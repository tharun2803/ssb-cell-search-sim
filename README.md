# SS/PBCH Block (SSB) & Initial Cell-Search Timing Simulator

A from-scratch Python simulation of how a 5G NR User Equipment (UE) finds a
cell on power-up: by detecting the **SS/PBCH Block (SSB)** through
**PSS/SSS correlation**. This models cell-ID detection, measures how
detection reliability degrades with SNR, estimates cell-search time, and
visualises the correlation peaks a real receiver would search for.

> Built as a simulation/coursework project. It follows the real 3GPP
> sequence-generation formulas for PSS and SSS, wrapped around a
> simplified OFDM/channel model — see [Scope & Simplifications](#scope--simplifications).

---

## What it does

1. **Generates real 3GPP NR PSS and SSS sequences** (TS 38.211 §7.4.2.2.1 / §7.4.2.3.1) — the exact length-127 BPSK sequences a real gNB transmits.
2. **Builds a simplified SSB waveform** (PSS → PBCH → SSS+PBCH → PBCH, 4 OFDM symbols) and passes it through an AWGN channel at an unknown timing offset — exactly the situation a UE faces at power-up.
3. **Implements the UE's two-stage cell search**:
   - Stage 1 — slide all 3 candidate PSS sequences across the received signal to jointly find **symbol timing** and **N_ID_2**.
   - Stage 2 — using that timing, FFT the SSS symbol and correlate against all 336 **N_ID_1** hypotheses.
   - Combine: `N_ID_cell = 3 × N_ID_1 + N_ID_2` (0–1007, matching the real NR cell-ID range).
4. **Runs a Monte Carlo sweep** of detection probability vs. SNR (the classic "waterfall curve").
5. **Estimates expected cell-search time** from the measured detection probability and the SSB periodicity.
6. **Visualises the PSS correlation peaks** — the plot a DSP engineer actually looks at when debugging a cell-search implementation.

```bash
git clone <this-repo-url>
cd ssb-cell-search-sim
pip install -r requirements.txt

python main.py
```

This runs one illustrative single search (with a correlation-peak plot) and

## Background: how initial cell search actually works

When a UE powers on, it has **no idea** what frequency offset, symbol
timing, or cell it's looking at. The gNB broadcasts an **SSB** periodically
(every 5–160 ms depending on config, commonly 20 ms) containing:

| Signal | Purpose |
|---|---|
| **PSS** (Primary Sync Signal) | 1-of-3 length-127 sequences → gives `N_ID_2` (0, 1, 2) + coarse symbol timing |
| **SSS** (Secondary Sync Signal) | 1-of-336 length-127 sequences (given `N_ID_2`) → gives `N_ID_1` (0–335) |
| **PBCH** | Carries the Master Information Block (MIB) — not modelled here |

```
Physical Cell ID = 3 × N_ID_1 + N_ID_2        (range: 0 – 1007)
```

The UE finds the SSB by **sliding correlation**: it tries all 3 PSS
waveforms against incoming samples at every possible sample offset. The
correlation peak reveals both *where* the SSB starts and *which* `N_ID_2`
it belongs to — solving timing acquisition and partial cell identification
in one step. Only after that does it decode SSS (and finally PBCH) to fully
identify the cell.

This project reproduces exactly that two-stage search.

## Results (as generated by this simulator)

### 1. PSS correlation peaks (single example search, SNR = −8 dB)

![PSS correlation peaks](results/plots/pss_correlation_peaks.png)

The true `N_ID_2` sequence (solid line) produces a clean correlation spike
at the true symbol boundary (red dotted line), while the two incorrect
candidate sequences (dashed) stay down in the noise floor — this is exactly
the search a UE's baseband performs on power-up.

### 2. Detection reliability vs. SNR

![Detection vs SNR](results/plots/detection_vs_snr.png)

A classic **waterfall curve**: near-zero detection probability at very low
SNR, a steep transition region, then a reliable detection floor around
+1.0 once SNR is high enough. Two curves are shown:
- **N_ID_2 correct** — success of Stage 1 (PSS) alone.
- **Full N_ID_cell correct** — success of the complete PSS+SSS chain (strictly harder, since it requires Stage 1 timing to be right *and* Stage 2 SSS decoding to succeed).

| SNR (dB) | P(N_ID_2 correct) | P(full cell-ID correct) |
|---:|---:|---:|
| −20 | 0.31 | 0.00 |
| −16 | 0.46 | 0.06 |
| −12 | 0.83 | 0.73 |
| −10 | 0.99 | 0.97 |
| −8  | 1.00 | 1.00 |
| 0   | 1.00 | 1.00 |

*(Full table with all swept points: [`results/detection_vs_snr.csv`](results/detection_vs_snr.csv). Regenerate any time with `python main.py`.)*

### 3. Estimated cell-search time vs. SNR

![Search time vs SNR](results/plots/search_time_vs_snr.png)

Using `E[search time] = (1 / P_detect) × SSB_period + processing_time`, a
UE in poor coverage (low SNR) may need to wait through **many repeated SSB
occasions** before successfully acquiring the cell, while in good coverage
it locks on almost immediately (bounded below by one SSB period +
processing time).

## Scope & simplifications

This is a **simulation for learning/demonstration**, not a full 5G NR PHY
stack. To keep the code readable and focused on the cell-search concept:

- **PSS/SSS sequence generation is exact** per 3GPP TS 38.211, including the m-sequence generator polynomials.
- **OFDM numerology is simplified**: a fixed 256-point FFT / arbitrary CP length is used instead of the real subcarrier-spacing-dependent NR numerology, and PSS/SSS occupy the centre subcarriers without avoiding the DC subcarrier as the real spec does.
- **PBCH is a placeholder**: random QPSK symbols fill the PBCH resource elements to give the SSB waveform realistic neighbouring-subcarrier energy, but the MIB payload, PBCH DM-RS, and channel coding are **not** implemented or decoded.
- **Channel model is AWGN only** — no multipath, no carrier-frequency offset (CFO), no fading, no beam sweeping across multiple SSBs in a burst set.
- **Cell-search time estimate** is a simple geometric-expectation model (`1/P_detect × SSB_period`), not a full RRC/NAS attach timeline.

These are natural next extensions if you want to take the project further
(see below).

## Possible extensions

- Add carrier-frequency offset (CFO) and test PSS detection robustness to frequency error.
- Add a multipath/fading channel model (e.g. TDL-A/B/C) instead of pure AWGN.
- Implement true NR numerology (µ=0..4 subcarrier spacing options) and DC-subcarrier puncturing.
- Model an SSB burst set (multiple SSBs per half-frame, beam sweeping) and combine energy across repetitions.
- Decode a placeholder PBCH payload (with real DM-RS + Polar coding) to fully replicate MIB acquisition.
